wi-mod is a local, portable, and unified mod library that gathers mod cards from multiple platforms — Nexus Mods, Modrinth, CurseForge, Steam Workshop, ModDB, and Independent sources — into a single hub on your PC. Rather than juggling a dozen browser tabs to track mods across games and sources, wi-mod lets you search, bookmark, and organise your entire multi-game collection in one place. It is not designed to replace advanced installation managers such as Mod Organizer 2 or Vortex; it is the **companion organisation tool** that sits alongside them, giving you a clean, offline-first library of everything you have found or plan to use.

## Key Features

<CardGroup cols={2}>
  <Card title="100% Portable" icon="box">

  <Card title="Privacy-First" icon="lock">
    Runs entirely locally. All data is stored in SQLite (desktop) or IndexedDB (web demo). No cloud account required, no telemetry, no data ever leaves your machine.
  </Card>
  <Card title="Multi-Platform Integration" icon="globe">

  </Card>
  <Card title="Dynamic Themes" icon="palette">

## Supported Platforms

wi-mod can fetch metadata and save mod cards from the following sources:

| Platform | Notes |
|---|---|
| **Nexus Mods** | Full metadata fetch via API key; download links available with free or Premium key |
| **Modrinth** | Open API; no key required for browsing |
| **CurseForge** | Requires a free CurseForge API key |
| **Steam Workshop** | Supported for tracking Workshop items |
| **ModDB** | Supported for games such as Fallout 4, New Vegas, and S.T.A.L.K.E.R. |
| **Independent** | Direct links to standalone mod pages outside the major platforms |

The set of available platforms shown for each mod entry is automatically narrowed to those relevant to the game in question. For example, Minecraft mods surface Modrinth and CurseForge, while most Bethesda RPG mods surface Nexus Mods as the primary source.

## Tech Stack

wi-mod runs two parallel desktop paths that share the same HTML/CSS/JS frontend in `web/`:

| Layer | Technology |
|---|---|
| **Desktop (current)** | Python 3 — `app.py` + `wi_mod/` package, local HTTP server via `pywebview` |
| **Desktop (migration target)** | Rust + Tauri v2 — `src-tauri/` (migration in progress) |
| **Frontend UI** | HTML5, CSS3, JavaScript — shared `web/` directory, also served via Vite |
| **Database** | SQLite on desktop · IndexedDB in the browser web demo |
| **API integrations** | Nexus Mods, Modrinth, CurseForge, Steam Workshop, ModDB, RAWG |
| **CI/CD** | GitHub Actions — automated Tauri builds for Windows and Linux, plus GitHub Pages deployment |

<Note>
  A live web demo is available at [wiarch.github.io/wi-mod](https://wiarch.github.io/wi-mod/). It runs the full frontend in your browser with data stored locally in IndexedDB — no download required to try out the interface.
</Note>
