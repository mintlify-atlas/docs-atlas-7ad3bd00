wi-mod is a local, portable mod library manager that brings together mods from Nexus Mods, Modrinth, CurseForge, Steam Workshop, and ModDB into a single unified interface on your PC. It stores everything in a local SQLite database — no accounts, no cloud sync, no telemetry — and ships as a single executable you can run from any folder.

## What wi-mod does

wi-mod is a **companion organization tool** — not a replacement for Mod Organizer 2 or Vortex. It lets you search, bookmark, and track mods across your entire multi-game library without juggling browser tabs. When you're ready, it can deploy mods into a game's `Data` folder using hardlinks or symlinks, and launch the game directly.

## Get up and running

<Steps>
  <Step title="Download">
    Go to the [Releases page](https://github.com/wiarch/wi-mod/releases/latest) and download the portable `.exe` (Windows) or `.AppImage` / binary (Linux). No installation required.
  </Step>
  <Step title="Configure API keys">
    Open **Settings** inside wi-mod and add your Nexus Mods API key (free). Optionally add CurseForge, RAWG, and Steam keys for full platform coverage.
  </Step>
  <Step title="Add your first mod">
    Paste a Nexus Mods, Modrinth, or CurseForge URL into the **Add Mod** dialog. wi-mod fetches metadata automatically and saves it to your local library.
  </Step>
  <Step title="Organize and launch">
    Create modpacks, set priorities, detect conflicts, then deploy and launch your game — all from within wi-mod.
  </Step>
</Steps>

<Note>
  wi-mod also runs as a [live web demo](https://wiarch.github.io/wi-mod/) in your browser. Data is stored locally in IndexedDB, so nothing leaves your machine.
</Note>
