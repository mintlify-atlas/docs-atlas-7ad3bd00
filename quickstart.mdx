This guide walks you through the first time you open wi-mod: configuring an API key, saving your first mod, and getting comfortable with the library interface. By the end you will have a working local library with at least one mod card saved and a clear picture of where to go next.

## First-Time Setup

<Steps>
  <Step title="Launch wi-mod">
    Download and run the portable executable for your platform. If you have not done that yet, see the [Installation](/installation) page for the download link and platform-specific notes.

    wi-mod opens directly to the library view. On the very first launch the library will be empty — that is expected.
  </Step>
  <Step title="Add your Nexus Mods API key">
    Open **Settings** (the gear icon in the sidebar) and navigate to the **API Keys** section. Paste your Nexus Mods personal API key into the Nexus field, then save.

    To get a free key:
    1. Log in at [nexusmods.com](https://www.nexusmods.com/users/myaccount?tab=api).
    2. Scroll to **API Keys** and click **Generate a new API key**.
    3. Copy the key and paste it into wi-mod's Settings.

    <Note>
      A free Nexus Mods key is sufficient for browsing mod metadata and descriptions. A **Premium** key is required to fetch direct download links. CurseForge also requires its own free API key, which you can add in the same Settings panel. Modrinth does not require a key for read access.
    </Note>
  </Step>
  <Step title="Add a mod by URL">
    In the main toolbar, click **Add Mod** (or the `+` button) and paste a mod URL into the input field. For example:

    ```
    https://www.nexusmods.com/skyrimspecialedition/mods/1
    ```

    wi-mod automatically detects the platform from the URL, calls the appropriate API, and fetches the mod's title, description, category, version, and thumbnail. The mod card is then saved to your local library — no manual data entry required.

    You can add mods from any supported platform using the same flow: paste a Nexus Mods, Modrinth, CurseForge, or ModDB URL and wi-mod handles the rest.
  </Step>
  <Step title="Browse your library">
    Return to the main **Library** view. You can filter and sort your saved mods using the controls at the top of the list:

    - **Game** — narrow the view to a single game (e.g. Skyrim Special Edition, Minecraft, Elden Ring).
    - **Platform** — show only mods from a specific source such as Nexus Mods or Modrinth.
    - **Category** — filter by mod type (gameplay, visuals, utilities, and so on).

    Click any mod card to open its detail view, which shows the full description, the source URL, and any notes you have added.

    <Tip>
      Use the **search bar** at the top of the library to find mods on Nexus Mods, Modrinth, or CurseForge directly from within wi-mod — without opening a browser. Results appear inline and any entry can be saved to your library in one click.
    </Tip>
  </Step>
  <Step title="Create a modpack (optional)">
    Once you have saved several related mods, use **Modpacks** to group them together. A modpack is a named collection — for example, "SSE Overhaul 2025" or "Minecraft Performance Pack" — that makes it easy to see which mods belong to a particular setup at a glance.

    Open the **Modpacks** section from the sidebar, click **New Modpack**, give it a name, and then add mods to it from your library.
  </Step>
</Steps>

## Offline Usage

<Note>
  Once mods are saved to your library, wi-mod works entirely without an internet connection. All metadata is stored locally in SQLite (desktop) or IndexedDB (web demo). An internet connection is only needed when fetching new mod metadata or checking for updates on a source platform.
</Note>
